# Google日本語入力

Google日本語入力の設定エクスポート。各ファイルは Google日本語入力のプロパティからインポートして使う。

## ファイル構成
| ファイル | 概要 |
|---|---|
| `google日本語入力-キー設定.txt` | キー設定 |
| `google日本語入力-ローマ字設定-月配列.txt` | ローマ字テーブル(月配列) |
| `google日本語入力-ユーザー辞書.txt` | ユーザー辞書(品詞順) |
| `google日本語入力_ユーザー辞書_記号.txt` | ユーザー辞書(記号) |
| `google日本語入力-ユーザー辞書-人名.txt` | ユーザー辞書(人名)。個人情報のため git 管理外(`.gitignore`) |
